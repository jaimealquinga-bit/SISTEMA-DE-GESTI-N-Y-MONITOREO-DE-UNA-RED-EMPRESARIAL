# Sistema de Gestión y Monitoreo de una Red Empresarial

Proyecto desarrollado para la asignatura de **Herramientas de Análisis de Datos / Desarrollo de Software** del **Instituto Superior Tecnológico CENESTUR** (Período Académico 2026 A).

## 🚀 Descripción del Proyecto
Sistema diseñado para centralizar la gestión de dispositivos de red (routers, switches, servidores), monitorear el estado de conectividad en tiempo real, registrar alertas automáticas ante fallas y administrar roles de usuario bajo una arquitectura cliente-servidor integrada con una simulación en Cisco Packet Tracer.
